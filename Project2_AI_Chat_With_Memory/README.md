# 💬 Multi-User Conversational AI with Memory

## 🌐 Live Demo

🔗 https://genaiprojects-kvawhjbsjna5tjbcfhrefy.streamlit.app

A professional conversational AI chatbot built using **Streamlit**, **LangChain**, **Groq**, and **Llama 3.3**. The application supports multiple user sessions with persistent conversation memory.

---

## 🚀 Features

- 🤖 AI Chat using Groq LLM
- 🧠 Conversation Memory
- 👥 Multi-User Session Support
- 💬 Chat History
- 🗑️ Clear Chat
- 📊 Conversation Statistics
- 🌡️ Adjustable Temperature
- 🔄 Multiple LLM Models
- 🎨 Professional Streamlit UI

---

## 🛠️ Technologies Used

- Python
- Streamlit
- LangChain
- LangChain Groq
- Groq API
- Llama 3.3 70B Versatile
