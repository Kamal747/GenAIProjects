## 📌 Project Overview

This project is an AI-powered text generation web application developed using **Streamlit**, **LangChain**, and **Groq LLM**. It enables users to enter prompts and generate intelligent, human-like responses in real time using Meta's **Llama 3.3** language model.

The application provides a simple and interactive interface for experimenting with Large Language Models (LLMs) while demonstrating how LangChain simplifies LLM integration.

---

## 🎯 Objective

The main objectives of this project are:

- Build an interactive AI-powered text generation web application.
- Integrate Groq's high-speed LLM inference engine.
- Demonstrate LangChain-based LLM integration.
- Provide secure API-based communication with Groq.
- Generate real-time AI responses through a user-friendly interface.

## 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/Kamal747/AI-Text-Generation.git
```

### Navigate into the project

```bash
cd AI-Text-Generation
```

### Create a virtual environment

```bash
python -m venv .venv
```

### Activate the virtual environment

Windows

```bash
.venv\Scripts\activate
```

Linux / macOS

```bash
source .venv/bin/activate
```

### Install dependencies

```bash
pip install -r requirements.txt
```

---

## ▶ Run the Application

```bash
streamlit run project1.py
```

---

## 🖥 Application Workflow

1. Launch the Streamlit application.
2. Enter your Groq API Key.
3. Select the Llama model.
4. Adjust the temperature if required.
5. Enter a prompt.
6. Click **Generate**.
7. View the AI-generated response.
